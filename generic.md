# Firmware checklist (control arm)

Written for the jury test in this repository as a representative generic checklist, not
quoted from any source. It exists so the sheet is measured against something, rather than
against nothing. If it beats `TASTE.md` on a case, that is a finding and it goes in
SCORES.md unedited.

- Write clean, readable, well-commented code.
- Follow a coding standard and keep functions short.
- Use version control and review every change.
- Test thoroughly before release, including edge cases.
- Handle errors gracefully.
- Avoid memory leaks and buffer overflows.
- Keep interrupt service routines efficient.
- Document the hardware interfaces.
- Use a watchdog timer.
- Optimise for power consumption on battery devices.
- Validate all external input.
- Keep firmware updates secure.
- Monitor devices in the field.
- Plan for backwards compatibility.
- Measure performance and profile hot paths.
