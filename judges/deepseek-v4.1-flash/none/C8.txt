The decision was to bind image verification to a monotonic anti-rollback counter ÔÇö a security version fused in one-time-programmable memory and raised on every update ÔÇö instead of trusting a valid signature alone. Signature verification proves only that an image is authentic, so an attacker can still flash a legitimately signed but year-old vulnerable build; a fused counter that never decreases makes the bootloader reject any image below the current security version, keeping the device on patched firmware.
